# 기부금영수증 · 국세청(홈택스) 연동 — 분석과 구현 기록

> 2026-10-16. 근거: 국세청 공개 안내 페이지, 법령 서식, 공개 검색 결과(아래 출처). **국세청은 연동 API를 공개하지 않으며,
> 홈택스 일괄발급 엑셀 양식의 열 구성도 공개 안내에 명시돼 있지 않다** — 이 부분은 추정하지 않고 설정 한 곳으로 분리했다.

## 2. 발견한 문제와 조치

| 심각도 | 문제 | 조치 |
|---|---|---|
| 치명 | 연말 일괄 발급이 매번 실패 — uuid 컬럼(`issued_by`)에 문자열 저장, 실패 시 번호·파일 연쇄 충돌 | 시스템 발급은 `null`, 공통 발급 모듈(`lib/receipt/issue.ts`) |
| 치명 | 국세청 파일이 **공식 규격이 아닌 자체 100바이트 고정길이** | 법정 발급명세 필드의 검증된 엑셀(XLSX)로 교체, 열 구성은 `NTS_COLUMNS` 한 곳 |
| 치명 | 온라인 후원 RRN이 국세청 자료에 안 들어감 — 신청 화면이 RRN을 보내지 않고, 들어와도 다른 테이블에 저장 | 신청 화면에 RRN·별도 동의 추가, 결제 확정 시 후원자 정보로 이전, 내보내기는 후원자→기존 영수증 순으로 조회 |
| 높음 | 번호가 count+1 — 동시 발급 시 중복·실패 / 결제마다 영수증(RC-…)과 연말 영수증(RCP-…) 두 형식 공존, 결제별 영수증 때문에 연말 발급에서 그 기부자 누락 | DB 카운터 `next_receipt_seq()`, 연 1장 원칙(결제별 영수증 제거) |
| 높음 | 관리자 발급이 호출마다 새 영수증 생성 | 유효 영수증 있으면 그대로 반환, 재발급은 명시적(`reissue=1`)·이전 영수증 취소 연결 |
| 높음 | 부분 환불 시 결제 전체가 빠짐, 전액 환불·취소 영수증도 국세청 자료에 포함 | 순액(금액−환불액) 집계, 취소·대체 영수증 제외 |
| 높음 | 진위 확인이 순차 번호로 조회 → 금액·이름 열람 가능, 기관 간 번호 중복 시 조회 실패 | 무작위 토큰(PDF QR) + 기관 범위 조회 |
| 높음 | 기관 법정 기재사항(대표자 등) 없음 | 기관 설정에 대표자·단체 구분·지정 근거·기부금단체코드 추가, 필수 누락 시 발급·내보내기 차단 |
| 높음 | 국세청 내보내기 이력이 한 번도 기록 안 됨(클라이언트가 빈 값 전송 → 400) | 서버에서 이력·감사 로그 기록 |
| 중간 | 주민번호 검증이 자릿수만 / 사업자번호 검증 없음 | 생년월일·성별 자리 검증(체크섬은 2020-10 이후 번호에 없어 미적용), 사업자번호 검증번호 확인 |
| 중간 | 고유식별정보 처리 동의 기록 없음 | 별도 동의 체크 필수 + `rrn_consent_at` 기록 |
| 중간 | 연도 경계가 UTC — 1/1 00~09시 후원이 전년도로 | 결제일 KST |
| 중간 | 주민번호 암호화 함수가 anon에서 호출 가능, 관리자 회원 수정 응답에 암호문 포함 | 실행 권한 service_role로 제한, 응답 컬럼 제한 |
| 중간 | 1000행 넘으면 집계·내보내기가 잘림 | 페이지 단위로 전부 읽기 |

## 3. 내린 결정 (표준 + 추천)

1. **연 1장 통합 영수증**(귀속연도 단위) — 결제별 즉시 영수증은 만들지 않는다.
2. **국세청 제출은 "홈택스 전자기부금영수증 일괄발급(엑셀 업로드)" 기준.** 연동 API가 공개돼 있지 않으므로 자동 전송 대신
   검증된 파일 + 제출 전 점검(제외 사유 목록)을 제공. 그해 홈택스 양식과 열 순서가 다르면 `NTS_COLUMNS`만 고친다.
3. **주민번호는 선택**: 없으면 영수증(PDF)은 발급하되 간소화 반영 불가를 안내하고 내보내기에서 사유와 함께 제외.
4. **체크섬 미적용**: 2020-10 이후 주민번호 뒷자리 무작위화로 체크섬이 정상 번호를 거부하기 때문.
5. **법정 기재사항 누락 시 발급 차단**(경고가 아니라 차단) — 기재사항 없는 영수증은 증빙 효력 다툼 소지.

## 4. 적용 순서 / 남은 확인

1. 마이그레이션 `20261016000004_receipts_integrity.sql` (카운터·토큰·기관 필드·동의 컬럼·권한)
2. 각 기관: 관리자 → 기관 설정에서 **대표자·소재지·사업자번호(검증번호)** 입력 — 비어 있으면 연말 발급이 중단된다
3. 홈택스 최신 일괄발급 양식을 받아 `NTS_COLUMNS` 열 순서 대조(기부유형 코드 열 필요 여부 포함)
4. 직전 연도 발급합계 3억 이상 기관은 전자기부금영수증 의무 — 운영 정책 안내 필요
5. 이전에 발급된 영수증은 진위 확인 토큰이 없다(QR 미표시) — 필요 시 재발급

## 홈택스 간소화 자료 제출 운영 메모 (2026-10-17 확인)
출처: 국세청 「간소화자료 제출 매뉴얼(기부금 단체용)」 2025 귀속분.
- 사전에 홈택스 「기부금 수령단체 자료제출 신청」 필요(이미 적격단체 승인 또는 국가기관은 불필요).
- 엑셀 양식은 **단체 ID로 로그인 후** 「영수증 발급처 자료제출 → 자료 제출하기 → 기부금 서식」에서만 받을 수 있다 → 열 구성은 여전히 공개 자료로 확인 불가. `NTS_COLUMNS`를 그 양식에 맞출 것.
- 제출 기한: 다음 해 1월 13일 22시(08~22시). 수정·추가분 1월 15~18일(18~22시).
- **재제출은 이전 제출분 전체를 대체** → 항상 연간 전체 파일을 올린다(우리 내보내기는 항상 연간 전체).
- 형식 검증: 주민번호 자릿수·레이아웃 오류 시 파일 전체 제출 불가. 내용 검증: 주민번호 없음·**중복**은 해당 건만 오류.
  → `buildNtsDataset`이 같은 번호를 한 줄로 합산하고(`merged`), 미리보기에 표시한다.
